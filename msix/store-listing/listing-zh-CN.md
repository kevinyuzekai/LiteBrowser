# Plume Browser — 商店文案（简体中文）

**产品名称**：Plume Browser
**类别**：生产力工具 / 实用工具
**价格**：免费

## 简短说明（≤100 字）
超轻量的网页浏览器：打开就能用，无需登录，安装包只有几 MB，历史记录只保存在你的电脑上。

## 描述
Plume Browser 基于 Windows 自带的 Microsoft Edge WebView2 内核，体积小、启动快、占用低。

- 无需注册或登录，打开即用
- 地址栏可直接输入网址或搜索内容，默认使用 Bing，可切换 Google、百度、DuckDuckGo
- 后退、前进、刷新、主页，多标签页与新窗口
- 本地历史记录：按日期显示标题、网址和时间，支持搜索、单条删除、一键清空
- 中文 / English 界面，自动跟随系统深色模式
- 常用快捷键：Ctrl+L 地址栏、Ctrl+R 刷新、Ctrl+[ / ] 后退前进、Ctrl+Y 历史、Ctrl+T 新标签页

## 功能列表（Product features）
1. 无需登录，打开即用
2. 地址栏支持网址与搜索
3. 多标签页、新窗口
4. 本地历史记录（搜索 / 删除 / 清空）
5. 多搜索引擎可选
6. 中英文界面，深色模式

## 隐私说明
Plume Browser 没有账号系统，不收集、不上传任何个人信息，不含广告和统计分析。浏览历史只保存在本机（应用数据目录下的 history.json），可随时在「历史记录」里删除或清空；卸载应用即删除。你访问的网站会按其自身隐私政策处理数据。
隐私政策网址（建议）：https://github.com/kevinyuzekai/Plume#隐私
